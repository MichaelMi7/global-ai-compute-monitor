# Release 0.2 assessment — 2026-11-04

The project now supplies an end-to-end public research workflow: evidence collection,
validated source ledgers, period normalization, accounting guards, infrastructure
comparisons, explicit scenario analysis, dashboard, portable exports and source alerts.
It is usable as an open research platform. It is not a completed measurement of the
world's private AI activity.

Evidence coverage: 11 token observations from six reporting entities; 14 infrastructure
records, including five labeled research estimates; 15 source pages. Latest seeded
publication is October 28, 2026. Several latest reports remain months old. Counts refer
to this sample, not market shares. The expanded source search was selective.

The most useful findings are accounting boundaries: new Google API reports cannot
extend its older all-surfaces series; router traffic is not additional provider traffic;
a national report does not establish consumption geography; access commitments and
future targets do not establish commissioned inference capacity. Compute-use estimates
include training and R&D and can overlap cloud ownership reports.

No comprehensive global token sum, effective global inference supply, matched global
tightness ratio or identified price elasticity is supportable from these inputs.
Missing telemetry is an open research limitation, not something additional code can
legitimately replace with an invented observation. The scenario tools allow explicit
hypotheses while preserving that distinction.

Next evidence work: expand current primary disclosures, obtain defined input/output and
model mixes, map owner/user/deployment overlap, and match commissioned inference fleets
to workload-specific production benchmarks. Validate economic assumptions against
independently measured prices/costs and held-out usage before making return claims.
